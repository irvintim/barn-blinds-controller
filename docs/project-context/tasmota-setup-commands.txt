# Step 8: Calibrate motor timing (run after physical installation)
#
# For each shade, run the calibration sequence:
#
#   ShutterSetClose1     -- tell Tasmota shade 1 is currently fully closed
#   ShutterOpen1         -- shade will open fully, Tasmota times it automatically
#   ShutterSetOpen1      -- tell Tasmota shade 1 is now fully open
#   ShutterClose1        -- shade will close fully, Tasmota times it automatically
#   ShutterSetClose1     -- confirm fully closed, calibration complete
#
# Repeat with ShutterSetClose2/ShutterOpen2 etc. for shades 2, 3, 4.
# After calibration, open/close durations are saved automatically.
# Re-run any time a motor or shade is replaced.
